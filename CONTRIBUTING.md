# Contributing Guidelines

Thank you for your interest in this AI Engineering Portfolio.

## Development Setup

1. Clone the repository:

```bash
git clone https://github.com/ShadowDemonOsprey/ai-engineering-portfolio.git
```

2. Create and activate the conda environment:

```bash
conda create -n ai-project python=3.13
conda activate ai-project
```

3. Install project dependencies:

```bash
pip install -r requirements.txt
```

## Code Guidelines

- Write clean and readable Python code.
- Add comments when logic is complex.
- Keep project documentation updated.
- Do not commit sensitive information such as API keys or passwords.

## Pull Requests

Before submitting changes:

- Test your code.
- Update documentation if needed.
- Ensure GitHub Actions checks pass.

Thank you for contributing.
