# Security Policy

## Reporting a Security Issue

If you discover a security issue in this repository, please report it responsibly.

Do not publicly disclose security vulnerabilities before they have been reviewed.

## Supported Versions

| Version | Supported |
|---|---|
| 1.0.x | Yes |

## Security Guidelines

- Never commit API keys or passwords.
- Never upload private credentials.
- Keep dependencies updated.
- Review code before deployment.
- Use environment variables for sensitive information.

## AI Project Considerations

For AI applications:

- Protect user data.
- Validate user inputs.
- Monitor external API usage.
- Avoid exposing confidential model information.
